3-1. 문자열을 만드는 3가지 따옴표와 템플릿 리터럴 ${ }

따옴표변수 끼워넣기여러 줄주로 쓰는 때

alert 에 백틱을 쓰는 게 아니라, 문자열 안에 변수를 넣고 싶을 때 백틱을 쓰는 것이다. 고정된 글자면 alert('안녕') 처럼 ' / " 로 충분하다.

// 작은따옴표 / 큰따옴표 안에서는 ${ } 가 동작하지 않는다 (글자 그대로 출력)
console.log('${i} 번째')

// 백틱은 여러 줄도 그대로 유지
console.log(`첫째 줄
둘째 줄`)

4. 문자열 메서드 : . 으로 호출하기

C++의 str.length(), C#의 str.ToUpper()처럼 값 뒤에 .을 찍고 기능(메서드)을 호출한다. 메서드가 새 값을 돌려주기 때문에 그 뒤에 .을 또 이어서 쓰는 메서드 체이닝도 가능하다.

JavaScript
let s = "Hello, JavaScript"
console.log(s.length)               // 17   ← 괄호가 없다! (메서드가 아니라 속성)
console.log(s.indexOf("Java"))      // 7    (찾은 위치, 없으면 -1)
console.log(s.indexOf("xyz"))       // -1
console.log(s.includes("Script"))   // true (포함 여부)
console.log(s.toUpperCase())        // 대문자로
console.log(s.toLowerCase())
console.log(s.slice(0, 5))          // 0번부터 5번 앞까지 잘라내기
console.log(s.replace("Hello", "Bye"))
console.log("ab".repeat(3))         // 반복
console.log("a,b,c".split(","))     // 쪼개서 배열로
console.log("  hi  ".trim())        // 앞뒤 공백 제거
console.log(s)                      // 원본은 그대로! (새 값을 돌려줄 뿐)

// 메서드 체이닝 : 결과에 바로 . 을 이어 씀
console.log("  hello  ".trim().toUpperCase().repeat(2))
메서드 / 속성하는 일
length글자 수 (속성이라 괄호 없음)
indexOf("x")처음 나오는 위치 (없으면 -1)
includes("x")포함하는지 true / false
slice(시작, 끝)일부 잘라내기 (끝은 미포함)
split("구분자")쪼개서 배열로
replace("a", "b")바꾸기 (처음 하나만. 전부는 replaceAll)
toUpperCase() / toLowerCase()대문자 / 소문자
trim()앞뒤 공백 제거
repeat(n)n번 반복
startsWith("x") / endsWith("x")시작 / 끝이 같은지

문자열은 수정할 수 없는 값(immutable)이다. 메서드는 원본을 바꾸는 게 아니라 새 문자열을 만들어 돌려준다. (C++ std::string과 다른 점)

== 와 === 의 차이 (매우 중요)

JavaScript
console.log(3 == "3")             // true   : == 는 타입을 맞춰서 비교 (자동 변환)
console.log(3 === "3")            // false  : === 는 타입까지 같아야 true
console.log(0 == "")              // true   (!)
console.log(0 === "")             // false
console.log(null == undefined)    // true
console.log(null === undefined)   // false
console.log(3 !== "3")            // true   : !== 는 === 의 반대

항상 ===, !==를 쓴다. ==는 자동 변환 때문에 예상 밖의 결과가 나온다. AI가 쓴 코드도 대부분 ===를 쓴다.

11-3. prototype : 모든 객체에 메서드 추가하기

자료형.prototype.이름 = ... 으로 속성이나 메서드를 추가하면 그 자료형으로 만든 모든 값에서 쓸 수 있다. 메서드 안에서 this 는 그 값 자신이다. 숫자 값은 this.valueOf(), 문자열이나 배열 안을 찾을 때는 this.indexOf() 를 쓴다.

JavaScript
try {
    // 1. 속성 추가 : 모든 Number 에서 보인다
    Number.prototype.sample = 10
    console.log((5).sample, (99).sample)         // 10 10

    // 2. 메서드 추가 : ** 는 거듭제곱 (2 ** 3 = 8)
    Number.prototype.power = function (n = 2) {
        return this.valueOf() ** n               // this.valueOf() = 숫자 값
    }
    console.log((3).power())                     // 9   (기본값 n = 2)
    console.log((2).power(3))                    // 8

    // 3. 문자열 / 배열 : this.indexOf() 로 안에 있는지 찾기
    String.prototype.has = function (word) {
        return this.indexOf(word) !== -1         // 없으면 -1
    }
    console.log("Hello JS".has("JS"), "Hello JS".has("xyz"))   // true false

    Array.prototype.has = function (item) {
        return this.indexOf(item) !== -1
    }
    console.log([10, 20, 30].has(20), [10, 20, 30].indexOf(20))  // true 1  (몇 번째 인덱스인지는 indexOf)
} finally {
    // 이 페이지의 다른 예제에 영향 주지 않도록 정리
    delete Number.prototype.sample
    delete Number.prototype.power
    delete String.prototype.has
    delete Array.prototype.has
}

내장 객체(Number, Array ...)의 prototype 을 건드리면 다른 코드나 라이브러리와 충돌할 수 있어서 실무에서는 피한다. 개념(모든 객체가 공유하는 메서드가 prototype 에 있다)을 이해하는 용도로 알아 두자. 그래서 위 예제도 끝에서 delete 로 되돌려 놓았다.

11-9. 전개 연산자로 복사하기 : 배열 [...], 객체 {...}
