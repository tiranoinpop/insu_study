React 스터디 2단락 : ES6 문법

교재 : 초보자를 위한 리액트 200제 예제 9~10 (실습은 Vite + React 19).
실습 코드 : github.com/tiranoinpop/react_study
보충 표시는 공부 노트에 없던 내용을 보강한 부분이다.

ES6(ECMAScript 2015) 는 JavaScript 의 큰 문법 개편이다. React 코드는 ES6 문법을 전제로 쓰여 있어서 먼저 익혀 둔다. (JavaScript 쪽 정리는 javascript_study.html 에도 있다.)

예제 9. ES6 문자열 : 템플릿 리터럴과 문자열 함수

실습 파일 : src/R009_Es6.jsx (App.jsx 에서 import Es6 from './R009_Es6' 후 <Es6 /> 로 사용)

componentDidMount() {
    // 기존 JavaScript : + 로 이어 붙이고, 줄바꿈은 \n
    var jsString1 = '자바스크립트'
    var jsString2 = '입니다.\n 다음 줄 입니다.'
    console.log(jsString1 + ' 문자열' + jsString2)

    // ES6 : 백틱(`) 과 ${ }
    var Es6String1 = 'ES6'
    var Es6String2 = '입니다.'
    console.log(`${Es6String1} 문자열 ${Es6String2}!!
______다음줄 입니다`)

    // ES6 에 추가된 String 함수
    var LongString = "ES6에 추가된 String 함수들입니다."
    console.log('startsWith : ' + LongString.startsWith("ES6에 추가"))
    console.log('endsWith : ' + LongString.endsWith("함수들입니다."))
    console.log('includes : ' + LongString.includes("추가된 String"))
}
// 콘솔
자바스크립트 문자열입니다.
 다음 줄 입니다.
ES6 문자열 입니다.!!
______다음줄 입니다
startsWith : true
endsWith : true
includes : true

9-1. 템플릿 리터럴 (Template Literal)

구분기존 방식ES6 방식
따옴표' ' 또는 " "백틱 ` ` (키보드 1 왼쪽의 `)
변수 끼우기a + ' 문자열' + b (+ 로 이어 붙임)`${a} 문자열 ${b}`
줄바꿈\n 을 써야 함코드에서 엔터를 친 그대로 줄바꿈이 된다
  • ${ } 안에는 변수뿐 아니라 JS 식도 넣을 수 있다 : `${a + b}`, `${x > 0 ? '양수' : '음수'}` 보충
  • 백틱 안의 들여쓰기·공백도 문자열에 그대로 포함된다. 위 예제의 ______ 는 줄 시작 위치를 눈에 보이게 하려고 넣은 것 보충
  • JSX 의 { } 와 모양이 비슷하지만 다르다. ${ } 는 백틱 문자열 안에서만 쓴다 보충

9-2. ES6 에 추가된 String 함수

함수하는 일예제 결과
startsWith(s)문자열이 s 로 시작하는가"ES6에 추가" → true
endsWith(s)문자열이 s 로 끝나는가"함수들입니다." → true
includes(s)문자열 안에 s 가 있는가 (위치 무관)"추가된 String" → true
  • 셋 다 true / false (Boolean) 를 반환한다
  • 대소문자를 구분한다 : "abc".includes("B") → false 보충
  • 예전에는 indexOf(s) !== -1 처럼 위치를 구해서 비교해야 했다. 이름만으로 뜻이 보이는 것이 장점 보충

예제 10. 변수 선언 : var, let, const

실습 파일 : src/R010_Variable.jsx

componentDidMount() {
    var varName = 'react';
    console.log('varName : ' + varName)
    var varName = 200;      // 경고는 뜨나 재선언 가능
    console.log('varName : ' + varName)

    let letName = 'react';
    console.log('letName : ' + letName)
    // let letName = 200;   // 재선언 불가
    letName = 200;          // 재할당 가능
    console.log('letName : ' + letName)

    const constName = 'react';
    console.log('constName : ' + constName)
    // const constName = 200;  // 재선언 불가
    // constName = 200;        // 재할당 불가
}
// 콘솔
varName : react
varName : 200
letName : react
letName : 200
constName : react
구분varletconst
재선언 (같은 이름으로 또 선언)가능 (경고만)불가불가
재할당 (값 바꾸기)가능가능불가
도입 시기예전부터ES6ES6
· 기본은 const, 값을 바꿔야 할 때만 let, var 는 쓰지 않는 것이 요즘 관례 보충
· var 는 실수로 같은 이름을 또 선언해도 조용히 덮어써서 버그를 찾기 어렵다 → let/const 는 에러로 막아준다
  • 예제의 // 경고는 뜨나 재선언 가능 : VS Code(ESLint) 에 경고 표시가 뜨지만 실행은 된다. 그래서 varName 이 react → 200 으로 찍힌다
  • 주석으로 막아 둔 두 줄은 주석을 풀면 에러가 난다 (재선언 불가 / 재할당 불가). 직접 풀어서 에러 메시지를 확인해 보면 좋다
  • componentDidMount 안에서 실행했으므로 결과는 화면이 아니라 브라우저 콘솔(F12) 에 나온다. 화면에는 [THIS IS VARIABLE] 만 보인다
추가 개념 보충설명
유효 범위(scope)var 는 함수 단위, let/const 는 블록 { } 단위. if, for 안에서 선언하면 그 밖에서는 안 보인다
const 와 객체const obj = { a: 1 } 에 obj.a = 2 는 가능. 막는 것은 obj = ... 처럼 변수 자체를 다른 값으로 바꾸는 것뿐
호이스팅var 는 선언 전에 써도 undefined 로 나오지만, let/const 는 선언 전에 쓰면 에러 (TDZ)

보충 이 예제를 만들 때 import React, { component } 처럼 Component 를 소문자로 쓰면 화면이 통째로 비어 보인다. extends Component 에서 에러가 나면 React 가 App 전체를 그리지 못하기 때문이다. 화면이 하얗게 나오면 먼저 콘솔(F12) 의 빨간 에러를 확인한다.

복습 퀴즈 (눌러서 답 확인)

1. 템플릿 리터럴은 어떤 따옴표로 쓰고, 변수는 어떻게 끼우나?

백틱(`) 으로 감싸고 ${변수} 로 끼운다. 줄바꿈도 엔터 그대로 된다.

2. startsWith, endsWith, includes 의 차이는?

각각 문자열이 ~로 시작하는지 / ~로 끝나는지 / ~를 포함하는지를 true/false 로 알려준다.

3. var, let, const 의 재선언·재할당 가능 여부는?

var : 둘 다 가능. let : 재선언 불가, 재할당 가능. const : 둘 다 불가.

4. 요즘은 어떤 순서로 선택하나?

기본은 const, 값이 바뀌어야 하면 let, var 는 쓰지 않는다.

5. const 로 선언한 객체의 속성은 바꿀 수 있나?

바꿀 수 있다. 변수에 다른 값을 다시 대입하는 것만 막힌다.

6. 화면이 하얗게 나올 때 가장 먼저 볼 곳은?

브라우저 콘솔(F12)의 에러 메시지. 예: Component 를 component 로 잘못 import 해도 화면 전체가 비어 보인다.
